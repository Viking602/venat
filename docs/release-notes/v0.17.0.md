# Venat v0.17.0

Status: **Released**

Released on 2026-09-21.

v0.17.0 adds bounded, application-controlled interaction to the direct Agent
SDK while preserving the execution transcript and durable boundaries.

## Agent execution controls

- Add `agent.Control` for queued user input, safe model-boundary
  acknowledgements, and cancellation of a running execution.
- Add session budgets, provider connect/request/stream-idle timeouts, and
  explicit validation for user content and control inputs.
- Add context-window fitting that preserves complete turns, cache prefixes,
  instructions, user constraints, errors, skill bodies, and full execution
  evidence while trimming only eligible tool output.
- Add structured-output recovery, tool feedback, and bounded continuation
  behavior around the same Agent loop.

## Provider, tool, and durable integration

- Add provider stream idle-timeout handling with identity preservation and
  deterministic timeout errors.
- Add optional model-assisted context selection through the typed tool kit;
  scores remain advisory and do not rewrite history.
- Extend durable and orchestration paths to retain the new control, timeout,
  context, and feedback state without introducing application policy.
