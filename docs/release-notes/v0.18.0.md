# Venat v0.18.0

Status: **Released**

Released on 2026-09-24.

v0.18.0 completes the streaming wire contracts for all three provider
protocols — OpenAI Chat Completions, OpenAI Responses, and Anthropic Messages —
and replaces representability rejections with a drop-and-warn policy. It also
adds self-correcting tool feedback when a model reaches for a tool name that is
not registered.

## Breaking changes

- Vendor API errors mid-stream now arrive as a terminal `Event{Kind: EventError}`
  followed by `io.EOF` instead of a bare `Recv()` error. Consumers must match on
  the terminal event (ADR-030: exactly one terminal event per stream).
- Unmappable request fields no longer fail at `Stream()` time. They are dropped
  with a `log/slog` warning via the new `provider/shared.WarnDrop`, and the
  request proceeds. Transport and protocol faults (non-2xx, non-SSE, malformed
  frames) remain hard errors.
- Truncated and empty streams uniformly surface `io.ErrUnexpectedEOF` on all
  three adapters, including before frame decoding so the default
  `OpenRetryingStream` policy classifies the failure as retryable.
- Responses hosted tool calls (`web_search_call`, `code_interpreter_call`,
  `file_search_call`) no longer surface as dispatchable tool-call events. The
  provider already executes them; their payloads stay in `ProviderState`, and
  only `function_call` sets the tool-use stop reason.

## Stream contract completion

- Map `ResponseFormat` faithfully on every wire: Chat Completions
  `response_format`, Responses `text.format`, and Anthropic
  `output_config.format` structured output, with `RawSchema` precedence and
  pre-flight validation of unsupported types.
- Map `Metadata`, `ExtraBody` (managed/protected merge), cache-boundary
  markers (`cache_control` / `prompt_cache_breakpoint`), and
  `tool_choice.disable_parallel_tool_use`.
- Report `ContextUsage` exactly once per stream from the authoritative wire
  location, including Anthropic `message.usage` input and cache tokens.
- Capture and replay `ProviderState` verbatim, including Anthropic content
  blocks with tool inputs, thinking signatures, and citations, and Responses
  built-in tool items, citations, logprobs, and audio payloads. Foreign
  provider state is rejected before replay with a fallback to plain content.
- Preserve SSE keepalive frames, reject unterminated terminal frames, and keep
  the cache marker after the complete message so cached prefixes cover trailing
  tool invocations.
- Add a cross-adapter stream conformance suite (`provider/stream_conformance_test.go`)
  pinning the shared `provider.Stream` contract across all three wires.

## Features

- Unknown tool-name rejections now carry the dispatchable tool names ranked by
  a deterministic name/description similarity heuristic with a `did you mean`
  hint, so a model reaching for a training-prior or hallucinated name
  self-corrects on its next turn. Subset buses disclose only their granted
  names.

## Fixes

- Keep Responses hosted tool calls out of local tool dispatch.
- Read Anthropic input usage from `message.usage` on `message_start`.
- Omit an absent Anthropic `system` value instead of sending an empty string.
- Reject an unterminated terminal Anthropic frame as truncated.
- Reject foreign array provider state (for example OpenAI Responses items)
  before Anthropic replay.
- Surface the truncation error before decoding partial Anthropic frames.
- Place Anthropic cache markers after the complete message.
